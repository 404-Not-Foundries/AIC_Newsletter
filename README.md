# AIC Newsletter — The Monday Drop

Interactive 3D weekly AI & tech newsletter with automated GroupMe Bot posting.

## Setup
1. **Enable GitHub Pages:** Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, select `main` / `/ (root)`, and save.
2. **Add GroupMe Bot Secret:** Go to **Settings → Secrets and variables → Actions → Secrets** and add `GROUPME_BOT_ID` with your bot's ID.
3. **Add Newsletter URL Variable (optional):** Under **Variables**, add `NEWSLETTER_URL` set to `https://404-not-foundries.github.io/AIC_Newsletter/`.
4. **Test It:** Open the **Actions** tab, select **Weekly GroupMe Newsletter Drop**, and click **Run workflow**.
